# 풀 좀 베겠습니다 (Excuse Me, Mowing through) - 게임 기획서

## 개요
풀을 베어서 돈을 모으는 방치형 모바일 게임.
플레이어가 이동하면 자동으로 범위 내 풀을 베고, 떨어진 코인을 수집하여 골드를 획득한다.

- **엔진**: Godot 4.3
- **장르**: 방치형 / 아이들 게임
- **플랫폼**: 모바일 (Android), PC

---

## 게임 플로우

```
메인 메뉴 → [PLAY] → 게임 세션 (타이머) → 세션 종료 → 메인 메뉴
             ├ [무기]  → 무기 상점 패널
             ├ [강화]  → 업그레이드 패널
             └ [QUIT]  → 게임 종료
```

### 메인 메뉴
- PLAY: 게임 세션 시작
- 무기: 무기 구매/업그레이드 패널
- 강화: 능력치 업그레이드 패널
- QUIT: 게임 종료
- 타이틀 "KILL GRASS" 숨쉬기 애니메이션

### 게임 세션
- 제한 시간 내에 최대한 풀을 베어 돈을 벌기
- 세션 시간: 60초 (현재 개발용 10초)
- 화면 상단 중앙에 남은 시간 표시
- 10초 이하일 때 타이머 빨간색으로 변경
- 세션 종료 시 보너스 코인 +$100 지급
- "세션 완료 보너스 +$100" 텍스트 표시
- 터치하여 메인 메뉴로 복귀
- 게임 중 "처음으로" 버튼으로 메뉴 복귀 가능 (확인 다이얼로그)

## 핵심 시스템

### 이동 방식
- 플레이어는 화면 중앙에 고정
- 월드(WorldRoot)가 플레이어 입력의 반대 방향으로 이동
- 배경은 카메라를 따라다니며 무한하게 보임
- 입력: 키보드 (WASD/방향키), 터치 드래그, 가상 조이스틱 (모바일)

### 무한 맵 (청크 시스템)
- 청크 기반 무한 풀 생성 (`grass_spawner.gd`)
- 청크 크기: 400x400
- 렌더 거리: 2 청크 (성능 최적화)
- 플레이어 주변 청크만 로드, 멀어지면 언로드
- 풀 밀도 업그레이드에 따라 청크당 풀 수 변동

### 풀 렌더링 (MultiMesh)
- MultiMeshInstance2D로 모든 풀을 1 draw call로 렌더링
- GPU 셰이더로 바람 흔들림 애니메이션 (CPU 부하 0)
- 풀 데이터는 Dictionary로 관리 (노드 없음)

### 풀 종류
| 종류 | 체력 | 드롭 | 재생시간 | 색상 |
|------|------|------|----------|------|
| 기본풀 | 4 | $1 | 22초 | 밝은 초록 |
| 강한풀 | 12 | $5 | 23초 | 청록색 |
| 완전 센풀 | 24 | $30 | 24초 | 어두운 청록 |
| 황금풀 | 60 | $100~500 | 25초 | 황금색 |

### 풀 등장 확률
- 황금풀: 모든 레벨에서 2% 고정
- 나머지는 풀 등급 업그레이드 레벨에 따라 변동:
  - Lv.0: 기본풀 100%
  - Lv.9: 기본풀 50% / 강한풀 50%
  - Lv.18: 강한풀 50% / 완전 센풀 50%
  - Lv.27+: 완전 센풀 100%

### 코인 시스템
- 풀을 베면 해당 위치에 코인 생성 (WorldRoot 자식)
- 코인 색상: 브론즈($0~99), 실버($100~499), 골드($500~999), 다이아($1,000+)
- 고액 코인(브론즈 $50+, 실버 $300+, 골드 $750+)은 피라미드형 3개 쌓인 비주얼
- 코인 스폰 시 팝 애니메이션
- 코인은 월드 좌표에 고정됨
- 자석 범위 내 접근 시 자동으로 끌려옴 (기본 75)
- 30 거리 내에서 자동 수집
- 수집 시 플로팅 텍스트 ("+금액") 표시

### 자동 공격
- 플레이어가 이동 중일 때 자동으로 범위 내 풀 공격
- 공격 주기: 0.2초 / 무기 속도배율
- 공격 범위: 80 * 무기 범위배율
- 피격 시 풀이 0.1초 동안 흰색 플래시
- 풀 체력이 0 이하가 되면 베어짐 → 코인 드롭

### 무기 시스템
10단계 무기 업그레이드 (별도 문서 참조: `무기정보.md`)
- 무기별 고유 외형 및 공격 애니메이션
- 공격 타입: single, double, spin, aura, flame, screen, world

### 업그레이드 시스템
4가지 능력치 강화 (별도 문서 참조: `업그레이드정보.md`)
- 풀 밀도, 수집 범위, 풀 등급, 풀 재생 속도

## 몬스터 시스템

### 몬스터 종류 (7종)
| 몬스터 | 체력 | 속도 | 스폰 가중치 | 드롭 |
|--------|------|------|-------------|------|
| 번개 먹은 슬라임 | 3 | 40 | 30 | 질긴 슬라임 조각, 번개 먹은 배터리 껍질 |
| 과성장 멧돼지 | 8 | 55 | 25 | 차축 뼈대, 굴러다니는 바퀴 잔해, 과성장 생체 응축체 |
| 잔디 기사 | 15 | 35 | 15 | 왜곡된 볼트 조각, 압축된 이세계 철편 |
| 스포어 마도사 | 12 | 45 | 15 | 생체 연료 포자, 뒤틀린 시간 포자, 바람 머금은 잔디 섬유 |
| 잔디 골렘 | 25 | 25 | 5 | 몬스터 핵, 압축된 이세계 철편, 침식된 백골 프레임 |
| 수정 사슴 | 18 | 60 | 5 | 투명 수정 파편, 강화 유리 결정핵 |
| 드래곤 배기가스 | 40 | 30 | 3 | 과열된 엔진 심장, 드래곤 배기가스 결정 |

### 몬스터 행동
- 배회 AI: 랜덤 방향 이동/대기 반복
- 5프레임 스프라이트 애니메이션 (0.18초/프레임)
- 이동 방향에 따라 좌우 반전
- 피격: 빨간 플래시 (0.15초)
- 사망: 확대 → 흔들림 + 페이드아웃 → 아이템 드롭
- 슬라임만 번개 이펙트 있음

### 스폰 규칙
- 세션 시작 시 8마리 스폰
- 플레이어 주변 반경 300~800에 배치
- 가중치 기반 랜덤 선택

## HUD 정보

- **상단 좌측**: 무기 정보 (이름, 레벨), 무기 스탯 (속도, 범위), 풀 밀도/수집 범위/풀 등급

### 디버그 UI (개발 빌드 전용)
- 데이터 초기화 버튼

## 저장/불러오기

### 저장 데이터
- 보유 골드
- 업그레이드 레벨 (풀 밀도, 수집 범위, 풀 등급, 풀 재생)
- 무기 레벨
- 인벤토리 (재료/부품 보유 수량)
- 발견된 아이템 목록

### 저장 시점
- 세션 종료 시 자동 저장
- 앱 종료 시 자동 저장

### 저장 경로
- `user://savegame.json` (JSON 형식)
- macOS: `~/Library/Application Support/Godot/app_userdata/풀 좀 베겠습니다/savegame.json`
