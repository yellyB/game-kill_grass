# **MVP 스펙 – 실제 개발 단위 분해**

## **MVP 목표 (다시 못 박기)**

- 풀 하나 베는 게 재밌다
- 10분 플레이 가능
- 저장되고 다시 켜면 이어진다

## **PHASE 0. 프로젝트 뼈대 (반나절)**

### **0-1. Godot 프로젝트 생성**

- Godot **4.3**
- 2D 템플릿
- 해상도: 세로 기준 (예: 1080x1920)

### **0-2. 기본 폴더 구조**

```jsx
/scenes
  /core
  /world
  /ui
/scripts
/resources
/autoload
```

### **0-3. Autoload 등록**

- GameManager.gd
- SessionManager.gd
- SaveManager.gd

> 이 세 개는 심장이다. 나중에 건들지 마라.
>

## **PHASE 1. 이동 & 월드 이동 (1일)**

### **1-1. Player (고정 캐릭터)**

- CharacterBody2D
- 위치 고정
- 입력 벡터만 계산

### **1-2. WorldRoot**

- Node2D
- 배경 + 풀 + 아이템 전부 자식
- 이동 입력의 **반대 방향으로 이동**

**완료 기준**

- 캐릭터는 중앙
- 입력하면 배경이 미끄러짐

---

## **PHASE 2. 풀 기본 시스템 (1.5일)**

### **2-1. Grass Scene**

- Area2D (Grass)
    - GrassVisual (Polygon2D)
    - CollisionShape2D
    - GPUParticles2D
    - RegenTimer
- 체력 변수
- 베기 함수

### **2-2. 자동 베기**

- Player에 Area2D 공격 범위
- 풀과 오버랩 시 자동 데미지

### **2-3. 풀 제거 & 재생**

- 베임 → 숨김 (cut state)
- Timer → 재생 (grow animation)

### **2-4. 무한 맵 (청크 시스템)**

- 청크 기반 풀 생성 (chunk_size: 400)
- 플레이어 주변 청크만 로드 (render_distance: 3)
- 멀어지면 청크 언로드
- 청크 좌표 seed로 일관된 생성

**완료 기준**

- 걸어가면 풀이 잘린다
- 시간이 지나면 다시 난다
- 무한히 걸어가도 새 풀이 생성된다

## **PHASE 3. 베기 손맛 (핵심, 2일)**

### **3-1. 타임 스케일 연출**

- 베기 순간:

### **3-3. 단면 연출**

- Sprite 변경 OR
- 파티클 1종

**완료 기준**

- 풀 베는 게 “기분 좋다”

> 이 단계에서 웃으면 MVP는 산다.

## **PHASE 4. 아이템 & 돈 (1일)**

### **4-1. 코인 드롭**

- 풀 베기 시 코인 드롭 (고정 값)
  - 일반 풀: 1원
  - 질긴 풀: 5원
  - 황금 풀: 10원
- 코인을 주워야 돈 증가
- 코인은 플레이어 근처에서 자석처럼 끌려옴

### **4-2. 돈 UI**

- 상단 숫자 증가 연출
- 코인 수집 시 플로팅 텍스트
  - 기본 금액: 노란색
  - 보상 증가 보너스: 초록색

**완료 기준**

- 베면 코인이 떨어진다
- 코인 주우면 숫자가 튄다
