# 아이템 & 제작 시스템

## 재료 아이템 (16종)

몬스터 드롭으로 획득. 사망 시 드롭 테이블의 가중치에 따라 1개 드롭.

| 재료 | 드롭 몬스터 | 사용처 |
|------|-------------|--------|
| 번개 먹은 배터리 껍질 | 슬라임 | 엔진 코어 |
| 질긴 슬라임 조각 | 슬라임 | 바퀴 |
| 차축 뼈대 | 멧돼지 | 바퀴 |
| 굴러다니는 바퀴 잔해 | 멧돼지 | 바퀴 |
| 과성장 생체 응축체 | 멧돼지 | 운전기사 |
| 왜곡된 볼트 조각 | 잔디 기사 | 바퀴 |
| 압축된 이세계 철편 | 잔디 기사, 골렘 | 범퍼, 유리 모듈 |
| 생체 연료 포자 | 마도사 | 범퍼 |
| 뒤틀린 시간 포자 | 마도사 | 내비게이션 |
| 바람 머금은 잔디 섬유 | 마도사 | 운전기사 |
| 몬스터 핵 | 골렘 | 범퍼, 내비게이션 |
| 침식된 백골 프레임 | 골렘 | 운전기사 |
| 투명 수정 파편 | 수정 사슴 | 유리 모듈 |
| 강화 유리 결정핵 | 수정 사슴 | 유리 모듈 |
| 과열된 엔진 심장 | 드래곤 | 엔진 코어 |
| 드래곤 배기가스 결정 | 드래곤 | 엔진 코어 |

## 부품 제작 (6종)

재료를 조합하여 중간 아이템(부품) 제작. 각 부품은 소지 수량에 비례하여 버프를 제공.

### 개념상 바퀴 (최종 필요 4개)

| 재료 | 수량 |
|------|------|
| 굴러다니는 바퀴 잔해 | 2 |
| 차축 뼈대 | 1 |
| 왜곡된 볼트 조각 | 8 |
| 질긴 슬라임 조각 | 4 |

**버프: 이동속도 증가** — 개당 +8%, 최대 +32%

### 폭발하는 엔진 코어 (최종 필요 10개)

| 재료 | 수량 |
|------|------|
| 과열된 엔진 심장 | 1 |
| 드래곤 배기가스 결정 | 2 |
| 번개 먹은 배터리 껍질 | 4 |

**버프: 공격범위 증가** — 개당 +10%, 최대 +100%

### 충격 무시 범퍼 (최종 필요 2개)

| 재료 | 수량 |
|------|------|
| 압축된 이세계 철편 | 5 |
| 생체 연료 포자 | 1 |
| 몬스터 핵 | 1 |

**버프: 피격 패널티 감소** — 개당 -25%, 최대 -50%

### 이세계 내비게이션 (최종 필요 1개)

| 재료 | 수량 |
|------|------|
| 뒤틀린 시간 포자 | 4 |
| 몬스터 핵 | 1 |

**버프: 몬스터 탐지** — 화면 밖 몬스터 위치를 빨간 화살표로 표시

### 강화 유리 모듈 (최종 필요 6개)

| 재료 | 수량 |
|------|------|
| 투명 수정 파편 | 8 |
| 강화 유리 결정핵 | 1 |
| 압축된 이세계 철편 | 1 |

**버프: 코인 수집 범위 증가** — 개당 +15%, 최대 +90%

### 운전기사 (최종 필요 1개)

| 재료 | 수량 |
|------|------|
| 바람 머금은 잔디 섬유 | 20 |

## 최종 조립: 이세계 트럭

부품 6종 + 졸음 약을 모두 모아 조립.

| 부품 | 필요 수량 |
|------|-----------|
| 개념상 바퀴 | 4 |
| 폭발하는 엔진 코어 | 10 |
| 충격 무시 범퍼 | 2 |
| 이세계 내비게이션 | 1 |
| 강화 유리 모듈 | 6 |
| 운전기사 | 1 |
| 졸음 약 | 1 |

- 졸음 약: 마지막 월드(용의 봉우리) 상자에서 드롭
- 부품 6종 완성 시 최종 조립 해금, 졸음 약 없으면 힌트 표시
