# 업그레이드 정보

## 업그레이드 비용

모든 업그레이드 공통 비용 공식:
```
비용 = 100 × 1.8^현재레벨
```

단, 특수 스킬(황금풀 확률, 드롭률 증가, 풀 보상)은 추가 배율 적용:
- **황금풀 확률:** `기본비용 × (5.0 + 현재레벨 × 16.2)`
- **드롭률 증가:** `기본비용 × (2.0 + 현재레벨 × 3.0)`
- **풀 보상:** `기본비용 × (2.0 + 현재레벨 × 3.0)`

## 풀 등급 (최대 Lv.8)

더 높은 등급의 풀이 등장할 확률이 증가합니다.

### 효과
- 황금풀은 기본 0.02%, 별도 스킬(황금풀 확률)로 증가
- 나머지에서 가중치 기반 3종 분배:
  - 기본풀: Lv.0에서 100%, Lv.6에서 ~2%, Lv.7+ 등장 안 함
  - 완전 센풀: Lv.2 이하 등장 안 함, Lv.3에서 ~2%, Lv.8에서 100%

## 업그레이드 UI

### 패널 위치
- 메인 메뉴: "강화" 버튼으로 열기
- 게임 중: 패널 토글 버튼 숨김 (메인 메뉴에서만 접근)

### UI 구성
- 무기 섹션: 현재 무기 이미지/이름/대미지 + 다음 무기 선택 버튼
- 스킬 트리: 7개 스킬 (풀 밀도, 풀 등급, 풀 재생, 풀 보상, 패널티 감소, 드롭률 증가, 황금풀 확률)
- 노드 상태: 완료(초록) / 구매 가능(골드+테두리) / 미공개(회색, "?")
- 설명 패널: 선택한 항목의 이름, 설명, 현재값→다음값, 비용 표시
- 구매 버튼: 무기와 스킬 모두 공용, 돈/스킬 부족 시 비활성화
