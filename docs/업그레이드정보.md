## 풀 등급 (최대 Lv.10)

더 높은 등급의 풀이 등장할 확률이 증가합니다.

### 효과
- 황금풀은 모든 레벨에서 2% 고정
- 나머지 98%에서 가중치 기반 3종 분배:
  - 기본풀: Lv.0에서 100%, Lv.7에서 ~2%, Lv.8+ 등장 안 함

## 업그레이드 UI

### 패널 위치
- 메인 메뉴: "강화" 버튼으로 열기
- 게임 중: 패널 토글 버튼 숨김 (메인 메뉴에서만 접근)

### UI 구성
- 무기 섹션: 현재 무기 이미지/이름/대미지 + 다음 무기 선택 버튼
- 스킬 트리: 4개 체인 (풀 밀도, 풀 등급, 풀 재생, 풀 보상) 세로 배치
- 노드 상태: 완료(초록) / 구매 가능(골드+테두리) / 미공개(회색, "?")
- 설명 패널: 선택한 항목의 이름, 설명, 현재값→다음값, 비용 표시
- 구매 버튼: 무기와 스킬 모두 공용, 돈/스킬 부족 시 비활성화
