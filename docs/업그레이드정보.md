## 업그레이드 UI

### 패널 위치
- 메인 메뉴: "강화" 버튼으로 열기
- 게임 중: 패널 토글 버튼 숨김 (메인 메뉴에서만 접근)

### UI 구성
- 4개 업그레이드 버튼 (현재 레벨 → 다음 레벨 표시)
- 선택 시 노란색 하이라이트
- 설명 패널: 이름, 설명, 현재값→다음값, 비용 표시
- 강화하기 버튼: 돈 부족 시 비활성화 + "돈 부족" 텍스트
- 최대 레벨 도달 시 "(MAX)" 표시
