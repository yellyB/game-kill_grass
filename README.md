# 풀 좀 베겠습니다 (Excuse Me, Mowing Through)

이동하면 주변 풀이 **자동으로 베어지고**, 떨어진 코인을 모아 무기·스킬을 키우며 7개 월드의 보스를 처치하는 방치형 로그라이트 모바일 게임입니다. Godot 4로 제작했으며 Google Play에 출시되어 있습니다.

> 🎮 **[Google Play에서 플레이하기](https://play.google.com/store/apps/details?id=com.yelly.killgrass)**

## 특징

- **무한 맵** — MultiMesh 기반 청크 스트리밍으로 수백 개의 풀을 단일 드로우 콜로 렌더링
- **GPU 셰이더 연출** — 정점 셰이더로 바람에 흔들리는 풀 애니메이션(CPU 부하 0), 색상 채널로 크리티컬·황금풀·피격 상태 표현
- **7개 월드 · 보스 전투** — 월드별 고유 배경·풀·BGM·분노 보스(슬라임·멧돼지·잔디 기사·마도사·수정 사슴·잔디 골렘·드래곤)
- **스킬 트리 업그레이드** — 무기·수확·탐험 3개 그룹, 16종 스킬. 보석으로 상위 레벨 해금
- **초월 시스템** — 클리어한 월드를 반복 강화하며 보상·난이도 스케일링
- **세션 기반 방치 플레이** — 45초 세션 동안 자동 수확, 종료 시 결과 정산 + 자동 저장

## 기술 스택

- **엔진**: Godot 4 / GDScript (36개 스크립트, 약 12,000줄)
- **렌더링**: MultiMesh2D, GPU 셰이더(GLSL)
- **아키텍처**: Autoload 싱글톤 + 시그널 기반 반응형 UI, 데이터 드리븐 설계(스킬·보스 정의를 선언형 테이블로 관리)
- **저장**: JSON 직렬화 로컬 세이브
- **밸런싱**: Python 시뮬레이터로 세션 수익·해금 소요시간 검증(`tools/simulate_world1.py`)
- **개발 도구**: Claude Code 기반 AI 페어 개발, AI 이미지 생성 프롬프트로 에셋 일관성 유지(`docs/image-prompts.md`)

## 프로젝트 구조

```

scenes/     씬(core / world / effects / ui)
resources/  셰이더·사운드·이미지·데이터 리소스
docs/       기획서·개발 계획·시스템 명세
tools/      밸런스 시뮬레이터
```
