# 스킬 트리 & 업그레이드 정보

## 그룹 구조

3개 그룹, 각 그룹 2열 그리드. 위에서 아래로 선행 스킬 연결.

### 무기 그룹
```
          [공격력]
          /      \
  [공격 속도]  [공격 범위]
      |              |
  [치명타 확률]  [몬스터 피해]
      |
  [치명타 피해]
```

### 수확 그룹
```
          [풀 밀도]
          /      \
  [풀 등급]  [수집 범위]
      |              |
  [황금풀 확률]  [공격 개수]
      |
  [황금풀 보상]
```

### 탐험 그룹
```
          [이동 속도]
           /      \
  [세션 시간]  [상자 확률]
           \      /
         [분노 속도]  ← OR (세션 시간 또는 상자 확률)
```

## 스킬 상세

### 공격력
- **서브/레벨:** 5 / 9 (총 45틱)
- **효과:** 공격력 증가
- **공식:** Lv.1~3: +1/틱, Lv.4~5: +2/틱, Lv.6~7: +3/틱, Lv.8~9: +4/틱
- **범위:** 1 → 106

### 공격 속도
- **서브/레벨:** 5 / 12 (총 60틱)
- **효과:** 공격 간격 감소
- **공식:** `0.7 - 틱 × 0.01` (초)
- **범위:** 0.70초 → 0.10초

### 공격 범위
- **서브/레벨:** 5 / 10 (총 50틱)
- **효과:** 풀 베기 반경 증가
- **공식:** `60 + 틱 × 4`
- **범위:** 60 → 260

### 공격 개수
- **서브/레벨:** 3 / 5 (총 15틱)
- **효과:** 한 번에 베는 풀의 개수 증가
- **공식:** 레벨별 틱당 증가 — Lv.1: +1, Lv.2: +2, Lv.3: +3, Lv.4: +4, Lv.5: +5
- **범위:** 1개 → 46개

### 치명타 확률
- **서브/레벨:** 5 / 8 (총 40틱)
- **효과:** 공격 시 크리티컬 발동 확률
- **공식:** `틱 × 2%`
- **범위:** 0% → 80%

### 치명타 피해
- **서브/레벨:** 5 / 6 (총 30틱)
- **효과:** 크리티컬 발동 시 데미지 배율
- **공식:** `120% + 틱 × 6%`
- **범위:** 120% → 300%

### 몬스터 피해
- **서브/레벨:** 5 / 7 (총 35틱)
- **효과:** 몬스터에 대한 추가 피해 배율
- **공식:** `100% + 틱 × 10%` (미정)
- **범위:** 100% → 450%

### 풀 밀도
- **서브/레벨:** 5 / 8 (총 40틱)
- **효과:** 구획당 풀 개수 증가
- **공식:** 레벨별 틱당 증가 — Lv.1: +1, Lv.2: +2, ..., Lv.8: +8
- **범위:** 1개 → 181개

### 풀 등급
- **서브/레벨:** 8 / 8 (총 64틱)
- **효과:** 높은 등급 풀 등장 확률 증가
- **방식:** 홀수 레벨: 다음 등급 50%까지, 짝수 레벨: 다음 등급 100%까지
- **등급:** 새싹 → 잔디 → 여린풀 → 강한풀 → 초강풀

### 황금풀 확률
- **서브/레벨:** 2 / 5 (총 10틱)
- **효과:** 황금풀 등장 확률 (미투자 시 0%, 황금풀 등장 안 함)
- **공식:** `틱 × 0.1%`
- **범위:** 0% → 1.0%

### 황금풀 보상
- **서브/레벨:** 5 / 5 (총 25틱)
- **효과:** 황금풀 코인 보상 (기본 100원)
- **공식:** 복리 — 1단계 틱당 ×1.10, 2단계 ×1.11, 3단계 ×1.12, 4단계 ×1.13, 5단계 ×1.14
- **범위:** 100원 → ~1,696원

### 이동 속도
- **서브/레벨:** 6 / 5 (총 30틱)
- **효과:** 플레이어 기본 이동 속도
- **공식:** `300 + 틱 × 10`
- **범위:** 300 → 600

### 세션 시간
- **서브/레벨:** 3 / 5 (총 15틱)
- **효과:** 세션 시간 증가
- **공식:** `45 + 틱 × 3` (초)
- **범위:** 45초 → 90초

### 수집 범위
- **서브/레벨:** 5 / 8 (총 40틱)
- **효과:** 코인 자동 수집 범위
- **공식:** `40 + 틱 × 4`
- **범위:** 40 → 200

### 상자 확률
- **서브/레벨:** 5 / 5 (총 25틱)
- **효과:** 새 청크 진입 시 상자 스폰 확률
- **공식:** `틱 × 0.2%`
- **범위:** 0% → 5%

### 분노 속도
- **서브/레벨:** 4 / 4 (총 16틱)
- **효과:** 몬스터분노 게이지 증가 배율
- **공식:** `100% + 틱 × 15%` (미정)
- **범위:** 100% → 340%
