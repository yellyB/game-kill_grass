## 공격 타입 설명

### single - 단일 베기
- 이동 방향으로 낫을 한 번 휘두름
- 120도 범위 스윙 애니메이션
- 해당 무기: 낡은 낫, 날 선 낫, 무거운 낫

### double - 이중 베기
- 앞뒤 두 개의 낫으로 동시 공격
- 360도 회전 스윙 애니메이션
- 해당 무기: 이중 낫

### spin - 회전 베기
- 이동 중 무기가 지속적으로 회전
- 별도 스윙 애니메이션 없이 연속 공격
- 해당 무기: 회전 예초낫

### aura - 오라 공격
- 접근만 해도 주변에 지속 피해
- 펄스(맥동) 애니메이션으로 범위 표시
- 오라 링 이펙트가 플레이어 주변을 감싸
- 해당 무기: 제초 기계, 분쇄 예초기

### flame - 화염 공격
- 높은 대미지의 화염 공격
- 불꽃 깜빡임 애니메이션
- 해당 무기: 화염 제초기

### screen - 화면 전체 공격
- 화면에 보이는 모든 풀에 피해
- 밝은 플래시 이펙트 + 맥동 링
- 해당 무기: 재앙 장치

### world - 맵 전체 공격
- 로드된 모든 청크의 풀에 피해
- 발광 오브 + 궤도 입자 애니메이션
- 해당 무기: 세계 정리자
