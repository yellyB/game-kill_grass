## 선행 조건

트리 연결 기반. 밀도/등급이 두 줄기, 가지로 뻗어나가는 구조.

```
밀도 ──→ 재생
밀도 ──→ 황금풀
등급 ──→ 보상
등급 ──→ 넉백
보상 ──→ 드롭률
```

| 스킬 | 최대 레벨 | 효과 |
|------|-----------|------|
| 풀 밀도 | 10 | 맵에 풀이 더 빽빽하게 자람 (양) |
